`latticed --data-dir DIR` serves the single-table SQL executor over the existing pgwire/TLS/SCRAM listener (#345, #412): it opens and replays a write-ahead log in DIR, runs the database on one thread behind a new `lattice_api::exec_host`, applies an explicit row policy per principal (`--development-policy` in trust mode, `--account-policies` in SCRAM mode, unlisted accounts denied, no allow-all default) and a statement timeout ceiling (`--statement-timeout-max-ms`). Committed rows and table names are recovered after a restart or crash; column definitions are not yet (#379), so a recovered table cannot be queried. Without `--data-dir` the `SELECT 1` placeholder is unchanged. Not done: the driver matrix, binary result formats and a persisted schema.
