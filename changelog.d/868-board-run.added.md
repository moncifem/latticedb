Board worker runner: `board run -- COMMAND` (or `--agent claude|codex`) takes tasks with `board next`, runs the command in its own process group with a scrubbed environment (no `PG*`, `BOARD_*` or `LATTICE_*` variable, the task text only in a private file), heartbeats on a separate thread, and maps the exit to the board (0 done, 75 retry with backoff, anything else a failure, a lost lease kills the group and marks nothing, SIGTERM releases the task). `board get` prints one task on one line for programs. `integrations/board/swarm` runs several workers with scripted agents that fail, hang or die and exits non-zero when the event log shows a task done twice, done by a non-holder, claimed twice or early, or lost; the `dev-stack` job runs it against a real latticed. New `docs/quickstart-agents.md`. Not done: a real `claude` or `codex` run (the templates were checked against `--help` and run only with stand-in executables), sandboxing of the child (the environment is scrubbed, the filesystem is not), fencing of the child's external side effects, pruning of old run directories, and any enforcement of who may approve a task.
