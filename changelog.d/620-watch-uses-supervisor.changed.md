`lattice watch` takes its retry policy from the SDK reconnect supervisor instead of its own doubling. A retry waits a random time between one second and a ceiling that starts at one second, doubles with each failure and stops at eight seconds; the ceiling returns to one second only after an event is printed, acknowledged and saved. Three failures in a row still stop the watch, and a refused token or a policy close still stops it at once. A protocol violation or an internal server error from the gateway is now retried up to that limit instead of stopping the watch. The watch still connects only to a loopback address, without TLS.
