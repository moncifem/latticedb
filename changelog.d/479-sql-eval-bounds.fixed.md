SQL expressions are now bounded: `LIKE` polls the statement timeout and cancellation while it matches, and `||` on text or bytea and `lower`/`upper` refuse a result over 16 MiB (`54000`) or over the remaining statement memory budget (`53200`) before building it, so a concatenation tree can no longer allocate without limit. `LIKE` is still O(text x pattern) in the worst case, as in PostgreSQL.
