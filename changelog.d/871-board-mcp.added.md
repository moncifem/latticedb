Board MCP server and Claude Code plugin: `integrations/board/board-mcp` serves the agent board as stdio MCP tools (list, show, queue, since, add, next, claim, heartbeat, note, done, fail, release), runs the `board` helper for every operation, hides the fence behind an opaque `lease_id`, takes the author from `BOARD_AUTHOR`, and returns board text as marked, bounded data. `integrations/board` is also a plugin (`/board:status`, `/board:next`, `/board:add`, a worker agent, a SessionStart digest, an ask gate on add, done and fail) listed by `.claude-plugin/marketplace.json`; `board queue` is a new read-only helper command. Not done: approve and cancel as tools (command line only on purpose), a push channel, and a model session that follows the slash commands.
