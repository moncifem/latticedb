The author-id registry, table-grant resolver and table-grant SQL property tests no longer pin their case counts (64, 256 and 32). They read `PROPTEST_CASES` like the rest of the suite, so pull requests run them at 10,000 cases and the ARM job at 256. Without the variable they run 256 cases each. The nightly 1,000,000-case run covers `lattice-core`, `lattice-abi` and `lattice-lsl` every night, and `lattice-sql` only when the nightly workflow is dispatched by hand with `sql_proptest` set.
