`RowStore::lookup_at_limited` now returns `RowError::NoSuchIndex` for an index that does not exist at the snapshot, like `lookup_at`, instead of an empty result. The row store refuses to commit a put whose key is over 4096 bytes (`RowError::KeyTooLong`, SQLSTATE `54000` in SQL), the change feed's key bound, so one oversize key can no longer make the feed fail for every reader. A log from before the rule that already holds such a key now fails only for readers allowed to read that row, with `FeedReadError::KeyTooLarge` naming the cursor to resume from. Deletes are not bounded. The bytes of the row-write and feed formats do not change.
