latticed reads its startup secrets through one private-file rule: the TLS key, the SCRAM verifier file, the decoy secret and the account policy file must each be an owner-only (mode 0600 or 0400) regular file in a directory that group and others cannot write to. A symlink or a FIFO in their place is refused, and the mode is checked on the open file that is read. Before, the verifier file had no mode check, and the other secrets followed a symlink and did not check the directory. On platforms other than Unix the server now refuses these files with an "unsupported" error instead of reading them unchecked. The certificate is public and is only checked to be a regular file.
