The Docker dev stack can publish the sync gateway and `POST /mcp` on 127.0.0.1 over TLS with the dev CA: set `LATTICE_DEV_GATEWAY_PORT` for `dev/lattice-dev.sh`. It is off by default, so the stack is unchanged unless the variable is set. It needs an image whose `latticed` serves the gateway over TLS. The dev-stack test runs the gateway steps on `LATTICE_DEV_IMAGE` and prints a skip with its reason when that image predates the TLS gateway.
