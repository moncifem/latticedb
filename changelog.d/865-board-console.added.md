Board console: `integrations/console/lattice-console serve` starts a read-only web page on `127.0.0.1` for the agent board, with the agents and what needs attention, a live event feed, one task with its parents and children, and a scorecard per agent that shows each metric's sample size and interval and says "not enough data" under its minimum. `serve --demo` shows it with generated data and no database. Standard-library Python only; board text is rendered as plain text under a strict Content-Security-Policy, a password in the URL is refused even when percent-encoded, and connections, query time and answer sizes are bounded. Not done: a login, TLS, a CI run against a real `latticed` (the unit tests use a fake `psql`), rework and spot-check metrics (the schema has no event for them), and leases or orchestration.
