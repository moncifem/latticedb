SQL transactions and session settings: the writes a `BEGIN` block (or one autocommit statement) stages are capped as a whole by the new `ExecLimits::transaction_bytes` (256 MiB by default), and the write that crosses it fails with `53200` and fails the block. `SET timezone`, `client_encoding` and `datestyle`, and the same startup parameters on the PostgreSQL wire, now accept only UTC, UTF8 and ISO and answer `22023` otherwise instead of being silently ignored; `SHOW` answers them. A driver that always sends a non-UTC `TimeZone` at startup must be set to UTC.
