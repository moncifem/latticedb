A result row, or a row description, too large for one PostgreSQL protocol message (1 MiB) now fails its statement with SQLSTATE 54000 before any of it is sent, and the connection stays usable. Before, the server dropped the connection in the middle of the reply. Values up to the limit are unchanged. Not done: a statement that writes in auto-commit mode and returns such a row has already committed its writes when the error is sent.
