A failed scheduled run of the nightly build, Kani, the I/O probe, the image, driver and quickstart smoke tests, zizmor or the OpenSSF Scorecard workflow now opens an issue labelled `scheduled-failure`, or comments on the open issue for that workflow, with the run URL and the failed jobs. Manual runs and pull requests open nothing. The nightly workflow keeps its own report, and the weekly workflow is not covered yet.
