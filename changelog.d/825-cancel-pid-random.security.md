Cancel keys draw the process id at random instead of from a counter, and a process id is not reissued while its slot holds it. A cancel request must now match an unpredictable id as well as the secret. The secret is still 32 bits, the width the protocol allows, and the threat model states the guessing budget: cancels are limited to 256 per second globally and 16 per client address, but wrong keys spend that budget and failed cancels are not backed off yet.
