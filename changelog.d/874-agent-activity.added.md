Live agent activity: `board activity` (off unless `BOARD_ACTIVITY=1`), `activity-list` and `activity-purge` record what each agent is doing now in two new tables, `agent_activity` and `agent_activity_log` (a ring of 200 writes per agent). The helper rate limits its own writes (one database write per agent and session per 5 seconds, calls in between counted locally) so a burst of tool calls is a few writes and not a connection each; a Claude Code hook (`integrations/board/hooks/activity-hook.py`, registered by the board plugin) reports tool name, a sanitised label and the outcome, blocks a tool call for at most 3 seconds, always exits 0 and prints nothing; `board run` publishes a row for the child it supervises. The console's Now screen shows each agent's tool activity, doing-now line and a sparkline of the last hour with the states working, quiet and "stuck?" (worded as "no tool activity for N min"), the needs-attention strip lists claimed tasks with a live lease and no tool activity, and a new Agent screen shows the timeline, tool mix and an active time estimate; the scorecard gains an active time per done task diagnostic with its n. Rows are reported by the agent's own hook and sampled: a compromised agent can lie, and only Claude Code hooks are verified.
