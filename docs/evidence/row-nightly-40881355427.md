## Reproduce the provenance audit

Use the repository and run id above rather than the current `main` or moving nightly label:

```sh
gh api repos/moncifem/latticedb/actions/runs/40881355427
gh api --paginate repos/moncifem/latticedb/actions/runs/40881355427/jobs
gh api --paginate repos/moncifem/latticedb/actions/runs/40881355427/artifacts
```

For every shard in the compact record, download the ZIP using
`gh api repos/moncifem/latticedb/actions/artifacts/ARTIFACT_ID/zip > artifact.zip`.
Compare `shasum -a 256 artifact.zip` with both its recorded `artifact_sha256` and the API's digest;
extract the log and compare its `log_sha256`. Match its exact `gate_shards::PROFILE_SHARD` passing
test and summary to the recorded profile, seed interval, steps, runs and verification counters.
Check four disjoint intervals per profile and sum shard counters to profile and aggregate totals.
These comparisons were performed for all 20 producer archives when collecting this record.
Artifacts are subject to GitHub retention; preserved digests identify missing bytes but cannot
recover an expired artifact.

For the native archive, first compare its SHA-256 above, then verify and inspect the signed source:

```sh
gh attestation verify lattice-nightly-aarch64-apple-darwin.tar.gz \
  --repo moncifem/latticedb --format json
```

Require the verified certificate's `sourceRepositoryDigest` and statement's resolved dependency
`gitCommit` to match the recorded source. Attestation binds archive bytes to their build provenance;
it does not itself prove runtime smoke behavior. The smoke observations are recorded separately.
